# Hospital Management System (HMS)

## Project Overview

This project is a **Hospital Management System (HMS)** developed as part of the SC/CE/CZ2002 Object-Oriented Design & Programming assignment at Nanyang Technological University.

The system is designed to automate common hospital operations, including **patient management, appointment scheduling, medical record management, prescription management, medication inventory management, and hospital staff administration**.

The application is implemented as a **Java Command Line Interface (CLI)** application and demonstrates the use of object-oriented programming principles and design concepts.

## Main Features

### Patient

- View medical records
- Update personal information
- View available appointment slots
- Schedule appointments
- Reschedule appointments
- Cancel appointments
- View scheduled appointments
- View past appointment outcome records

### Doctor

- View patient medical records
- Update patient medical records
- View personal schedule
- Set appointment availability
- Accept or decline appointment requests
- View upcoming appointments
- Record appointment outcomes

### Pharmacist

- View appointment outcome records
- Update prescription status
- View medication inventory
- Submit medication replenishment requests

### Administrator

- View and manage hospital staff
- View appointment details
- Manage medication inventory
- Approve medication replenishment requests
- Import initial staff, patient, and inventory data

### Authentication

- User login using hospital ID and password
- Role-based access to system functionality
- First-time password change
- Login validation and error handling

## Object-Oriented Design

The project applies key object-oriented concepts, including:

- **Encapsulation**
- **Inheritance**
- **Polymorphism**
- **Abstraction**
- **Class relationships**
- **Separation of responsibilities**

The design also considers:

- Coupling and cohesion
- Extensibility
- Maintainability
- Design patterns
- Design trade-offs
